2. DETAILED BREAKDOWN OF EVERY TECHNOLOGY USED
================================================================================

--------------------------------------------------------------------------------
A. REACT.JS (v19) — Frontend Framework
--------------------------------------------------------------------------------
- WHAT IS IT:
  A modern, industry-standard JavaScript library created by Meta for building fast, 
  dynamic user interfaces using reusable modular components.

- WHERE IT IS USED IN THIS PROJECT:
  * Entry file: src/main.jsx, src/App.jsx
  * All 11 Pages:
    1. src/pages/HomePage.jsx (Hero banner, weather widget, featured seeds)
    2. src/pages/CatalogPage.jsx (Dynamic seed/fertilizer filtering & search)
    3. src/pages/ProductDetailPage.jsx (Agronomy specs, pack selector, audio guidance)
    4. src/pages/CartPage.jsx (Kisan subsidy coupon engine, price breakdown)
    5. src/pages/CheckoutPage.jsx (UPI QR, Card, and Cash on Delivery forms)
    6. src/pages/OrderTrackingPage.jsx (5-stage live delivery progress stepper)
    7. src/pages/FarmerDashboardPage.jsx (Kisan rewards points & active dispatches)
    8. src/pages/AdminDashboardPage.jsx (Store management, inventory CRUD, KPIs)
    9. src/pages/CropDoctorPage.jsx (AI plant pathology leaf diagnosis scanner)
    10. src/pages/AuthPage.jsx (Dedicated login & rural farm registration)
    11. src/pages/PresentationDeckPage.jsx (Interactive project presentation deck)

- WHY WE CHOSE IT:
  Enables Single Page Application (SPA) behavior where the user switches screens, 
  applies filters, or changes languages instantly in milliseconds with ZERO page flicker.


--------------------------------------------------------------------------------
B. VITE (v8) — Next-Generation Frontend Tooling
--------------------------------------------------------------------------------
- WHAT IS IT:
  A high-performance build tool and local development server that replaces older, 
  slow tools like Webpack and Create-React-App.

- WHERE IT IS USED IN THIS PROJECT:
  * Configuration: vite.config.js
  * Build scripts: package.json ("dev": "vite", "build": "vite build")

- WHY WE CHOSE IT:
  Provides instant server start (under 300ms), Hot Module Replacement (HMR), 
  and optimized production bundling (dist/) that loads smoothly even on 3G rural mobile networks.


--------------------------------------------------------------------------------
C. TAILWIND CSS (v4) — Utility-First Styling Framework
--------------------------------------------------------------------------------
- WHAT IS IT:
  A utility-first CSS framework that allows creating custom, responsive, and 
  modern designs directly inside HTML/JSX markup.

- WHERE IT IS USED IN THIS PROJECT:
  * Global theme & directives: src/index.css
  * Styling across every component (gradients, glassmorphism, responsive grid layouts)

- WHY WE CHOSE IT:
  Gives our platform a professional "Agriculture Emerald & Gold" look (deep forest greens, 
  vibrant amber badges, soft mint backgrounds) and automatically adapts to mobile phones, 
  tablets, and desktop screens.


--------------------------------------------------------------------------------
D. REACT ROUTER (v7) — Client-Side Application Routing
--------------------------------------------------------------------------------
- WHAT IS IT:
  The standard routing library for React that enables seamless page navigation 
  without reloading the browser.

- WHERE IT IS USED IN THIS PROJECT:
  * Router setup: src/App.jsx (<BrowserRouter>, <Routes>, <Route>)
  * Navigation links: src/components/common/Navbar.jsx, MobileBottomNav.jsx, Footer.jsx

- WHY WE CHOSE IT:
  Maintains clean URL paths (e.g. /catalog, /track, /crop-doctor, /dashboard) while 
  preserving global state (cart, logged-in farmer session) during transitions.


--------------------------------------------------------------------------------
E. LUCIDE REACT — Vector Iconography Library
--------------------------------------------------------------------------------
- WHAT IS IT:
  An open-source, lightweight icon library providing crisp SVG icons.

- WHERE IT IS USED IN THIS PROJECT:
  * Seeds & Plants: Sprout, Leaf, Sparkles
  * Verification & Quality: ShieldCheck, CheckCircle2, Award, QrCode
  * Logistics & Delivery: Truck, Package, Clock, Phone, MapPin
  * Interaction: Heart, ShoppingCart, Volume2, VolumeX, MessageSquare, Sun, Droplets

- WHY WE CHOSE IT:
  Visual cues are essential for farmers who may have difficulty reading dense text. 
  Icons help users understand actions immediately (e.g., green shield = certified lot).


--------------------------------------------------------------------------------
F. WEB SPEECH SYNTHESIS API — Native Browser Text-to-Speech Engine
--------------------------------------------------------------------------------
- WHAT IS IT:
  A standard browser JavaScript API (window.speechSynthesis) that converts text into 
  spoken audio in regional languages without requiring external paid speech APIs.

- WHERE IT IS USED IN THIS PROJECT:
  * src/pages/ProductDetailPage.jsx ("Listen to Details" button for seed specs)
  * src/pages/CropDoctorPage.jsx ("Listen Diagnosis" button for plant disease cures)
  * src/components/common/KisanChatbot.jsx ("Listen Audio" response playback)

- WHY WE CHOSE IT:
  Solves the digital illiteracy barrier for rural farmers by speaking out instructions 
  in Indian regional accents (Hindi hi-IN, Punjabi pa-IN, Telugu te-IN, English en-IN).


--------------------------------------------------------------------------------
G. REACT CONTEXT API — Global State Architecture
--------------------------------------------------------------------------------
- WHAT IS IT:
  React's built-in state management mechanism for sharing data across all components 
  without messy "prop drilling".

- WHERE IT IS USED IN THIS PROJECT (5 Global Context Providers):
  1. src/context/LanguageContext.jsx: Manages 4-language i18n switching and localization.
  2. src/context/AuthContext.jsx: Manages farmer & admin login sessions and demo profiles.
  3. src/context/CartContext.jsx: Manages cart items, pack selections, and subsidy calculations.
  4. src/context/WishlistContext.jsx: Manages bookmarking certified seed varieties.
  5. src/context/NotificationContext.jsx: Manages real-time alert center and unread badges.

- WHY WE CHOSE IT:
  Keeps the application modular, organized, and lightweight without needing heavy 
  external dependencies like Redux.


--------------------------------------------------------------------------------
H. LOCALSTORAGE API — Client-Side Data Persistence
--------------------------------------------------------------------------------
- WHAT IS IT:
  Standard browser key-value database that survives page refreshes and browser restarts.

- WHERE IT IS USED IN THIS PROJECT:
  * Storing farmer registrations (agriseed_user)
  * Storing placed orders and tracking info (agriseed_orders)
  * Storing cart items (agriseed_cart) and saved wishlist items (agriseed_wishlist)
  * Storing selected language preference (agriseed_lang)

- WHY WE CHOSE IT:
  Enables a zero-latency experience where farmers do not lose their cart or orders 
  even if their internet connection disconnects momentarily.


--------------------------------------------------------------------------------
I. PYTHON / FLASK — Backend Web Framework & REST API
--------------------------------------------------------------------------------
- WHAT IS IT:
  A lightweight, secure Python backend microframework for creating RESTful API 
  endpoints and handling business logic.

- WHERE IT IS USED IN THIS PROJECT:
  * File: app.py
  * Endpoints: /api/products, /api/auth/register, /api/auth/login, /api/orders, /api/diagnose

- WHY WE CHOSE IT:
  Python is ideal for agricultural data handling, future Machine Learning integration 
  (TensorFlow / PyTorch for leaf disease detection), and clean REST API development.


--------------------------------------------------------------------------------
J. SQLITE / RELATIONAL DATABASE — Persistent Data Store
--------------------------------------------------------------------------------
- WHAT IS IT:
  A structured relational database engine using SQL (Structured Query Language).

- WHERE IT IS USED IN THIS PROJECT:
  * File: instance/agriseed.db or schema.sql
  * Tables:
    - users (farmer id, name, phone, village, district, land size, reward points)
    - products (seed lot, category, germination rate %, purity %, price, stock)
    - orders (order id, farmer id, items, total, status, tracking details)
    - diagnostics (leaf scan record, pathogen identified, prescription)

- WHY WE CHOSE IT:
  Ensures ACID compliance, reliable financial transaction tracking for seed purchases, 
  and scalable data queries.


--------------------------------------------------------------------------------
K. NGROK — Secure Dev Tunneling Tool
--------------------------------------------------------------------------------
- WHAT IS IT:
  A network reverse-proxy tool that creates a secure public HTTPS URL pointing to 
  your local laptop's localhost port.

- WHERE IT IS USED IN THIS PROJECT:
  * Command: ngrok http 5173

- WHY WE CHOSE IT:
  Allows you to instantly open and demo your live project on your smartphone, 
  or share the link with your project guide/evaluator anywhere in the world.

3. SPECIALIZED SMART MODULES & ALGORITHMS
================================================================================

1. MULTILINGUAL DICTIONARY ENGINE (src/data/translations.js):
   - Comprehensive multi-language dictionary mapping over 200+ agricultural terms, 
     botanical names, and UI elements across English, Hindi, Punjabi, and Telugu.
   - Dynamic interpolation for currency formatting (₹), pack weights, and localized dosages.

2. AI PLANT PATHOLOGY DIAGNOSIS ENGINE (src/pages/CropDoctorPage.jsx):
   - Analyzes crop leaf photos for biological fungal, bacterial, and pest symptoms 
     (e.g., Paddy Leaf Blast - Magnaporthe oryzae, Cotton Pink Bollworm).
   - Generates instant agronomic prescriptions, chemical active ingredient dosages, 
     and preventative cultural practices with 1-click remedy ordering.

3. REGIONAL DOPPLER WEATHER ADVISORY (src/components/home/WeatherAdvisoryWidget.jsx):
   - Computes state-level climate suitability parameters (temperature, relative humidity %, 
     precipitation probability, and soil moisture levels).
   - Matches local conditions against optimal sowing calendar windows for Kharif/Rabi crops.

4. 5-STAGE LOGISTICS TRACKING PIPELINE (src/pages/OrderTrackingPage.jsx):
   - Simulates end-to-end rural logistics: Ordered -> Confirmed -> Shipped -> Out for Delivery -> Delivered.
   - Exposes dispatch fleet registration number, courier partner, driver contact, and destination farm details.

5. ICAR LOT CERTIFICATION & TAX INVOICE GENERATOR (src/components/common/InvoiceModal.jsx):
   - Formats computer-generated GST tax invoices complete with verified ICAR lab testing seals, 
     QR verification hashes, government subsidy deductions, and browser print/PDF export.
